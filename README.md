# 6.4 Assignment: Paws & Company

A small cat-and-dog discovery page built with plain HTML, CSS, and JavaScript. Open `index.html` in a browser; there is no install or build step.

## Rubric

- **Object:** Each pet in the `pets` array is an object with descriptive properties.
- **Object Method:** Pet objects provide methods for their description and birthday, plus an age accessor.
- **Array:** `pets` is the collection of available companions.
- **Array Method:** The page uses `filter`, `map`, `sort`, and `reduce` to search, render, sort, and count pets.

The pet ages and birthday labels use JavaScript `Date` and `Intl.DateTimeFormat`.
